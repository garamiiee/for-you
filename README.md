## About

**오다 주웠어..♥**는 친구와 하찮은 물건을 주고받는 서비스입니다.

돌멩이, 양말 한 짝, 낙엽처럼 별것 아닌 물건을 발견하고,
짧은 한마디와 함께 친구에게 건넬 수 있습니다.

친구와 주고받은 물건들은 사라지지 않고 둘만의 공간에 하나씩 쌓입니다.

처음에는 별것 아니었던 물건들이 쌓이면서
둘 사이의 작은 기록이 되어가는 경험을 만드는 것이 목표입니다.

# u2netp.onnx

U^2-Net (small, 4.6MB) — 이미지에서 주요 피사체를 찾아내는 모델이에요.
`rembg` 가 기본으로 쓰는 것과 같은 모델이고, 배경 제거를 키·쿼터 없이
우리 서버 안에서 처리하려고 함께 배포해요.
